# 오늘 뭐 버려? 설치하기

앱스토어가 아닙니다. 본인 맥의 Xcode로 아이폰에 올립니다. 개발자가 아니어도 아래 순서만 따라 하면 됩니다.

처음 열면 집 도시를 고르고, 알림·위젯 붙이는 법이 나옵니다. 이미 도시를 고른 뒤에는 이 안내가 다시 뜨지 않습니다.

---

## 준비

- 맥
- App Store에서 **Xcode** 설치. 첫 실행 때 추가 구성 요소를 끝까지 기다립니다.
- 아이폰, 또는 시뮬레이터만 볼 때
- 무료 Apple ID면 충분합니다. 유료 개발자 계정은 필요 없습니다.

---

## 아이폰에 올리기

1. 아이폰: **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켠 뒤 재시작합니다.
2. 케이블로 맥과 연결합니다. 아이폰에서 **이 컴퓨터를 신뢰**를 누릅니다.
3. Xcode에서 `jejuonl/jejuonl.xcodeproj` 를 엽니다. 다른 폴더의 프로젝트가 아닙니다.
4. 왼쪽 위(또는 가운데) 스킴을 **jejuonl** 로 고릅니다.
   - `jejuonlWidget` / `jejuonlWidgetExtension` 이면 앱이 아니라 위젯만 실행합니다. 쓰지 마세요.
   - 목록에 `jejuonl`이 없으면 **Product → Scheme → Manage Schemes → Autocreate Schemes Now**.
5. Signing: TARGETS **jejuonl** 과 **jejuonlWidget** 모두 **같은 Team** (본인 Apple ID).
6. 기기 목록에서 본인 아이폰을 고른 뒤 ▶ Run 합니다. 아이폰에 앱이 뜨면 끝입니다.
7. “신뢰할 수 없는 개발자”가 뜨면 아이폰 **설정 → 일반 → VPN 및 기기 관리 → 개발자 앱 → 신뢰**.

---

## 시뮬레이터만 볼 때

스킴 **jejuonl** + iPhone 시뮬레이터 → ▶ Run.

Signing에 **Your team has no devices** 가 떠도 시뮬레이터 Run은 됩니다. 실기기는 아이폰을 한 번 연결하면 프로파일이 생깁니다.

---

## 홈 화면에 위젯 붙이기

앱이 위젯을 대신 붙일 수는 없습니다. 홈 화면에서 직접 추가합니다.

1. 홈 화면 **빈곳을 길게** 누릅니다. 앱이 흔들릴 때까지.
2. 왼쪽 위 **+** 를 누릅니다.
3. **오늘 뭐 버려?** 를 검색한 뒤 **작은 / 넓은 / 큰** 칸을 고릅니다.

**위젯을 길게 눌러 제주시/서귀포시를 고르세요.** 칸마다 도시를 따로 둘 수 있습니다.

---

## 알림

온보딩에서 **알림 받기**를 누르면 시스템이 권한을 묻습니다. **나중에**를 누르면 묻지 않습니다. 나중에 앱 설정에서 켤 수 있습니다.

**알림을 쓰려면 일주일에 한 번은 앱을 여세요.** 앱이 7일치를 미리 예약합니다. 일주일 이상 안 열면 알림이 끊깁니다.

---

## 무료 Apple ID

무료 Apple ID로 올리면 **약 7일마다 Xcode로 다시 설치**해야 앱이 열립니다. 만료되면 위와 같이 스킴 `jejuonl`로 ▶ Run 한 번 더 하면 됩니다.

---

## 확인

- 알림을 거부했거나 끈 뒤에는 아이폰 **설정 앱 → 알림 → 오늘 뭐 버려?** 에서 다시 켤 수 있습니다. 앱 설정에도 안내가 뜹니다.
- 아이폰을 재부팅해도 이미 예약해 둔 알림은 유지됩니다.
- 기기 시간대가 서울이 아니어도, 창구 시간과 알림은 **서울 15:00 / 04:00** 기준입니다.
- 위젯 도시와 앱 도시가 달라도 됩니다. 위젯은 길게 눌러 고른 시, 앱·알림은 헤더에서 고른 시를 씁니다.
